# Sajan Bajgain — Portfolio

Personal portfolio website for Sajan Bajgain, IT Support & Cybersecurity Specialist based in Sydney, NSW.

**Live site:** [sajan-bajgain.github.io](https://sajan-bajgain.github.io)

## Stack

- Pure HTML / CSS / JavaScript — no frameworks, no build step
- Fonts via Google Fonts (IBM Plex Mono, Fraunces, DM Sans)
- Contact form via Formspree
- Canvas-based animated node grid background

## Files

```
index.html   — Main portfolio page
style.css    — All styles
script.js    — Canvas, typed text, scroll reveal, mobile menu, form
```

## Deploy

1. Push to `main` branch
2. Enable GitHub Pages → Source: `main` → `/ (root)`
3. Site goes live at `https://<username>.github.io`
